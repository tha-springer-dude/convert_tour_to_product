# Tamino Tour to WooCommerce Product

A custom WordPress plugin that connects Tour Booking Manager with WooCommerce by automatically converting tour entries into purchasable digital products.

## Features

- Converts Tour Booking Manager tours into WooCommerce products.
- Transfers tour titles, descriptions, prices and featured images.
- Generates downloadable PDF travel documents using TCPDF.
- Transfers tour gallery images into WooCommerce product galleries.
- Supports multilingual products through Polylang.
- Links translated products across languages.
- Creates virtual and downloadable WooCommerce products.
- Generates product SKUs based on tour IDs.
- Provides a custom add-to-cart interface with adult and child selection.
- Uses tour duration and organizer information for product presentation.

## Technical Details

- **Platform:** WordPress
- **E-commerce:** WooCommerce
- **Tour Management:** Tour Booking Manager
- **Language:** PHP
- **PDF Library:** TCPDF
- **JavaScript:** jQuery
- **Multilingual Support:** Polylang
- **Custom Fields:** WordPress post metadata

## Workflow

1. A tour is created in Tour Booking Manager.
2. The plugin retrieves the tour information and associated media.
3. A corresponding WooCommerce product is generated.
4. A PDF travel document is created and attached as a downloadable product file.
5. Gallery images and multilingual product relationships are transferred.
6. Customers can purchase the resulting digital product through WooCommerce.

## Project Context

Developed for Tamino Travel to connect tour management with e-commerce and automate the creation of digital travel products.
